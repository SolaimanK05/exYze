# Catalogue models

One `.glb` per catalogue code, named `<code>.glb`. The codes and sizes are in `docs/catalogue.md`.

- **Source:** Kenney Furniture Kit 1.0 (CC0), https://kenney.nl/assets/furniture-kit. No credit is required, but the author is Kenney.
- **Conversion:** each OBJ was converted to glTF binary, scaled by one factor for the whole set (1 Kenney unit = 0.175 m) and moved so the model stands on the floor with its footprint centred on the origin. No model is stretched, so the proportions are the artist's.
- **Size:** 25 files, 347 KB in total, the largest 39 KB.
- **Colours:** flat material colours, no textures.
